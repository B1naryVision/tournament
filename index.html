The qualifiers

Storming the Gate

The main event seats sixteen. If more than sixteen banners are pledged, the qualifiers decide which of them ride — fought under your own gamertag, not an alias. The draw is random, and byes are handed out at random depending on how many turn up. The mask comes later, so the qualifiers are followed openly: bring your friends, and let them watch you climb.

Season I · Open enlistment

Pledge Your Banner

Enlistment is uncapped; the main event is not. Sixteen lords ride in it, and if more than sixteen banners are pledged the qualifiers decide which sixteen — random draw, random byes. So bring every lord you know; a bigger field only makes the gate harder to storm. Your alias is not yours to pick — it is assigned once the field is settled, and from that moment it is the only name the audience sees until the crown is decided.

Required

Install the Stronghold 2 Unofficial Patch before you play. Every lord must be on the latest release — it fixes a long list of the crash bugs that end multiplayer games early, and an unpatched client is grounds to forfeit.

Download the latest release from GitHub — B1naryVision/sh2-unofficial-patch. Both sides run the same version, checked at muster.
